Brainlyy 🧠

Brainlyy is a desktop-based interactive quiz application built with Python and Tkinter. It provides a simple and engaging quiz experience with timed multiple-choice questions, instant answer feedback, score calculation, percentage, and performance grading.

Features

Multiple-choice quiz questions

10-second timer for each question

Instant correct/wrong answer feedback

Automatic score calculation

Percentage and performance grading

Restart quiz option

Exit option

Clean mobile-inspired user interface


Technologies Used

Python

Tkinter


How to Run

1. Make sure Python is installed on your computer.


2. Clone or download this repository.


3. Open the project folder.


4. Run the following command:



python quiz_app.py

Working

The application follows a simple quiz flow:

Home Screen → Quiz Questions → Answer Feedback → Final Result

Project Purpose

This project was developed to practice Python programming, GUI development with Tkinter, event handling, timers, and basic application logic.
